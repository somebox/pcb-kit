# The pattern of an overview page

`pcbkit overview` makes a page to the pattern in this kit's `docs/CONVENTIONS.md`, "The overview page", and a page
built by hand for one round's question (an order checked line by line, a housing in 3-D) follows it. Three built by
hand on 2026-11-17 show it, in this kit's README: Orbitchron's before its first order, DodecaRGB's control board
v1.3 order review, the RGB spotlight's lamp housing review at round 7. What they add to that list:

- **The top says where it stands, without scrolling**: a title that names the thing and the moment ("Control board
  v1.3, before the JLC order"), two or three sentences, the state in a few chips, three or four numbers (size,
  parts, cost per board, open findings) and a picture of the thing.
- **What changed since the user last looked comes next**: each number with its earlier value struck through beside
  it, then a table of part, then → now, and why.
- **The viewer compares**: a board as a render, layer by layer or as an assembly map, front and back; or one view
  with a button per round, so two rounds compare in place.
- **A block** has a map of where it sits, close-ups of its copper, and its findings and decisions as cards.
- **Decisions are sorted by whose move it is**: for the user, decided this round, still open, carried over.
- **Every card cites its source**: the finding's or decision's number (F29, D30) as a link, and the file it is in.
- The page says which round it shows and when it was last updated.
